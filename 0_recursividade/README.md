# Recursividade
Repositório para estudos e testes usando recursividade durante as aulas de Estrutura de Dados.

### Métodos
- Fatorial: Calcula o fatorial do valor N.
- Sequência de Fibonacci: Calcula elemento do valor de posição N.
- "2 elevado": Calcula quanto seria 2 elevado ao valor N.
- Maior número em Vetor[n]: Verifica qual o elemento de maior valor dentro de um vetor de tamanho N.
